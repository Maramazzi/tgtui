# tgtui

Минималистичный Telegram клиент для терминала в стиле nano.

## Установка

```bash
git clone https://github.com/you/tgtui
cd tgtui
./install.sh
```

После установки получи API ключи на https://my.telegram.org и запусти:

```bash
tgtui
```

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `↑↓` | Навигация по списку |
| `←→` / `Tab` | Переключение панелей |
| `[ ]` | Переключение папок |
| `Enter` | Открыть чат |
| `R` | Ответить на сообщение |
| `E` | Редактировать сообщение |
| `D` | Удалить сообщение |
| `Y` | Копировать текст |
| `^F` | Поиск |
| `^Q` | Выход |
| `F1` | Помощь |

## Аргументы запуска

```bash
tgtui                    # запуск
tgtui --debug            # лог в ~/.config/tgtui/debug.log
tgtui --theme light      # светлая тема
tgtui --theme no_color   # без цвета
```

## Требования

- Python 3.10+
- Linux или macOS
